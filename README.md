# 🍄 Mario Jump Game

Um jogo interativo de corrida infinita inspirado no clássico Super Mario Bros, desenvolvido com HTML5, CSS3 e JavaScript puro.

## 🎮 Jogar Online

Você pode jogar o jogo diretamente no seu navegador através do link:  
👉 **[Clique aqui para jogar](https://arthus-dev.github.io/mario-jump-game/)**

---

## 🚀 Sobre o Projeto

O objetivo do jogo é ajudar o Mário a desviar-se dos obstáculos (tubos) pondo à prova os reflexos do jogador. Conforme o jogador avança e salta os obstáculos, a sua pontuação aumenta até ocorrer uma colisão, disparando a tela de Game Over.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página
- **CSS3:** Estilização responsiva em tela cheia, animações `@keyframes` e transições
- **JavaScript (Vanilla):** Manipulação de DOM, escutadores de eventos de teclado, lógica de salto e detecção de colisão em tempo real via `setInterval`

---

## 🕹️ Como Jogar

1. Acesse o [link do jogo](https://arthus-dev.github.io/mario-jump-game/).
2. Pressione a **Seta para Cima** ou a **Barra de Espaço** no teclado para fazer o Mário pular.
3. Evite encostar nos tubos para não perder!
