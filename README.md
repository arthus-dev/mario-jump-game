# 🍄 Mario Jump Game

Um jogo interativo infinita inspirado no clássico Super Mário Bros e a mesma vibe do Dino, desenvolvido com HTML5, CSS3 e JavaScript puro.

## 🚀 Sobre o Projeto

O objetivo do jogo é ajudar o Mário a se desviar dos obstáculos (tubos) pondo à prova os reflexos do jogador. Conforme o jogador avança e pula os obstáculos, sua pontuação aumenta até ocorrer uma colisão, disparando a tela de Game Over.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da página
- **CSS3:** Estilização responsiva (100vh/100vw), animações 'keyframes' e transições
- **JavaScript (Vanilla):** Manipulação de DOM, escutadores de eventos de teclado, lógica de pulo e detecção de colisão em tempo real via 'setInterval'

- ## 🎮 Como Jogar
- 
1. Abra o projeto no navegador.
2. Pressione a **Seta para Cima** ou a **Barra de Espaço** no teclado para fazer o Mário pular.
3. Evite encostar nos tubos para não perder!
